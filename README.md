# The 64-Copy Problem — XXZ Phase Recognition

**Team: Few and Curious**
Alexandria Quantum Hackathon 2026, Track 2.

Classify the phase of an unknown 16-qubit ground state (FM / XY / NEEL) from at
most 64 measured copies, flag states from a foreign Hamiltonian family as
`UNKNOWN`, and do it with a circuit whose parameter count does not depend on
system size.

## Approach

Every copy is passed through a trained circuit and measured in the computational
basis. The resulting bits feed two independent decisions:

1. **Family check.** `gap = <pair> - <c1>`, the wire-pair correlation minus the
   neighbour correlation. An XXZ chain is translation invariant, so the two agree
   and `gap ~ 0`. Jordan-Wigner places a Fermi-Hubbard site on wires `(2i, 2i+1)`,
   so for the impostor family they disagree (`gap ~ -0.25`). States below
   `mu - 3 sigma / sqrt(k)` are rejected. The bound is calibrated on XXZ training
   states only.
2. **Phase.** Each copy is reduced to `(|m|, staggered magnetization)`, matched to
   a discrete symbol, and per-copy log-likelihoods are accumulated with the prior
   applied once.

Both decisions read the same measurements, so no copies are reserved for the
family check.

## Models

| | parameters | structure |
|---|---|---|
| Brickwork (submitted) | 16 | one two-qubit kernel applied at every bond, two layers |
| Shared QCNN | 18 | convolve, pool, halve; parameters tied across rounds |

Parameters are shared across position, so a longer chain means more gate
placements rather than more parameters:

| N | 4 | 8 | 16 | 24 | 64 |
|---|---|---|---|---|---|
| Brickwork | 16 | 16 | 16 | 16 | 16 |
| Shared QCNN | 18 | 18 | 18 | 18 | 18 |

The kernel is built from `RX`, `IsingXX`, `IsingYY` and `IsingZZ`, all of which
commute with the global spin flip, so the circuit cannot learn a magnetization
sign — correct, since the two symmetry-broken ferromagnetic sectors are one phase.

Depolarizing noise reduces to an independent bit flip at rate `2p/3` in the
measurement basis, which lets the likelihood tables be built under the noise
channel analytically rather than by sampling. Measured gain at `p = 0.1`:
+0.062 accuracy over noise-blind tables.

Classical baselines under the same 64-copy budget, on a mixed validation set of
near-boundary XXZ states and Fermi-Hubbard impostors:

| protocol | macro-F1 | applies gates |
|---|---|---|
| CNN on raw bitstrings | 0.922 | no |
| Order-parameter likelihood | 0.888 | no |
| Brickwork (quantum) | 0.851 | yes |
| Classical shadows + logistic regression | 0.801 | yes |

The classical baselines are size-independent by construction as well — the CNN
uses global mean pooling and the shadow features are translation-averaged — so the
comparison is like-for-like.

Measurement sampling in the provided oracle is not seeded, so repeated runs of the
same protocol on the same data vary with a standard deviation of about 0.066 in
macro-F1. Single-run differences below roughly 0.19 are not significant. The
three-seed table above is averaged; the single-run tables are not.

## Running

```bash
conda env create -f environment.yml
conda activate qphase64
pip install -e .
```

Score a submission with the organizers' scorer:

```bash
cd datasets/SEND_TO_PARTICIPANTS-1
python evaluate.py ../../submissions/quantum/submission.py \
    --data <states>.npz --key <key>.csv --noise_p 0.02 --budget 64
```

Retrain and rebuild the submission (about 55 minutes):

```bash
python scripts/build_xxz_submission.py --steps 300
```

Full sweep — two models, three seeds, noise levels, impostors, ablations (about
2.5 hours):

```bash
python scripts/run_xxz_quantum.py --seeds 0 1 2 --steps 300
```

The oracle rebuilds its circuit and re-prepares a 65,536-amplitude state on every
call, at roughly 493 ms per copy, so scoring the quantum submission costs about
32 seconds per state.

## Notes

- Training uses the 48 provided states; the near-boundary states used for
  evaluation are generated by exact diagonalization and reproduce the provided
  states to fidelity 1.000000 at matching anisotropy.
- The provided training set contains no impostors, so the family check is derived
  from the Jordan-Wigner geometry rather than learned.
- Two-copy entangled measurement was not implementable: the oracle prepares a
  single state per circuit, so two copies can never be made coherent.
